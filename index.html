Bring order to your media library.

MediaAtlas (片序) is a Windows desktop application designed to organize and manage media libraries stored on connected cloud storage and local file systems — with metadata-assisted suggestions and human review before anything is changed.

Key features

Everything you need to organize a large library.

MediaAtlas focuses on the workflow that actually gets messy in real libraries: scanning a deep folder tree, associating subtitles, matching metadata, and renaming files — with a preview and a human sign-off before any change lands on disk.

Cloud Storage Integration

  • Connect to supported cloud storage services.
  • Browse remote folders and files.
  • Work with user-selected directories.

Batch File Renaming

  • CSV-based file renaming.
  • Preview before execution.
  • Operation history and undo.

Intelligent Media Organization

  • Recursive directory scanning.
  • Video and subtitle association.
  • Movie and TV metadata lookup.
  • Suggested folder and filename organization.
  • Human review before file operations.

Metadata Integration

  • TMDB integration planned for movie and TV metadata.
  • AniDB and TVDB integration planned.
  • Episode numbering and metadata matching.

AI-Assisted Review

  • AI-assisted verification of metadata matching.
  • Configurable AI API providers.
  • Human approval before applying changes.
Development status

MediaAtlas 2.4 is in development.

The feature list above describes the current design goals for the 2.4 line. Not every feature has been completed or validated against real-world media libraries at this stage, and behavior may change before release.

In development

Version 2.4

Active development of the Windows desktop application: library scanning, subtitle association, CSV-based batch renaming, preview and undo, and human-reviewed organization suggestions.

Planned

Metadata integrations

TMDB integration for movie and TV metadata is planned, along with AniDB and TVDB. Episode numbering and metadata matching are part of the design goals for the 2.4 line.

Design goal

AI-assisted review

AI-assisted verification of metadata matches with configurable providers, gated behind explicit human approval before any change is applied to your files.

Independence & attribution

Clear about what MediaAtlas is — and isn’t.

MediaAtlas is an independent project and is not affiliated with or endorsed by TMDB.

This product uses the TMDB API but is not endorsed or certified by TMDB.

MediaAtlas does not redistribute media content. It only reorganizes and renames files that the user already owns and has explicitly selected. All file operations require human review before they are applied.
