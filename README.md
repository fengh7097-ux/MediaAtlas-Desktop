# MediaAtlas (片序)

**Version 2.4 — In Development**

MediaAtlas is a Windows desktop application designed to organize and manage media libraries stored on connected cloud storage and local file systems.

---

## Overview

MediaAtlas (片序) helps you bring order to large personal media libraries. Point it at a connected cloud storage mount or a local folder, let it scan your video and subtitle files, and use metadata-assisted suggestions to clean up folder and file names — always with your review before anything is changed.

This repository hosts the public project homepage and release-independent information. Application source code, installers, user data, and credentials are **not** published here.

## Platform

- **OS:** Windows 10 / Windows 11
- **Distribution:** Windows desktop application
- **Current release line:** 2.4 (in active development; not yet generally available)

## Key Features

### Cloud Storage Integration
- Connect to supported cloud storage services.
- Browse remote folders and files.
- Work with user-selected directories.

### Batch File Renaming
- CSV-based file renaming.
- Preview before execution.
- Operation history and undo.

### Intelligent Media Organization
- Recursive directory scanning.
- Video and subtitle association.
- Movie and TV metadata lookup.
- Suggested folder and filename organization.
- Human review before any file operation is applied.

### Metadata Integration
- TMDB integration planned for movie and TV metadata.
- AniDB and TVDB integration planned.
- Episode numbering and metadata matching.

### AI-Assisted Review
- AI-assisted verification of metadata matching.
- Configurable AI API providers.
- Human approval before applying changes.

## Development Status

MediaAtlas 2.4 is **in development**. Features listed above describe the current design goals for the 2.4 line. Not every feature has been completed or validated against real-world media libraries at this stage, and behavior may change before release.

## Roadmap

- Continue validating intelligent organization on large, mixed movie/TV/anime libraries.
- Complete TMDB integration and ship metadata-assisted renaming.
- Explore AniDB and TVDB integrations.
- Improve subtitle-to-episode matching accuracy.
- Expand AI-assisted review providers and moderation flows.

## Project Independence

MediaAtlas is an independent project and is **not affiliated with or endorsed by TMDB**.

This product uses the TMDB API but is not endorsed or certified by TMDB.

MediaAtlas does not redistribute media content. It only reorganizes and renames files that the user already owns and has explicitly selected.
